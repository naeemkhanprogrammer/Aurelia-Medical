## Layouts

- `app/layout.tsx` — `<html>`, fonts, global metadata (`metadataBase`, title template `%s | Aurelia Medical Group`, robots).
- `app/(marketing)/layout.tsx` — `SiteShell` (skip link, header, `<main id="main-content">`, footer).
- `app/not-found.tsx` renders `SiteShell` itself (it sits outside the route group).
- `(marketing)/loading.tsx`, `(marketing)/error.tsx`, `global-error.tsx`.

## Next 16 conventions used

- `params` is a Promise: `const { slug } = await params` with the global `PageProps<"/doctors/[slug]">` type (generated by `next typegen`).
- `generateStaticParams` + `export const dynamicParams = false`.
- `next/image` uses `preload` (the `priority` prop is deprecated in 16).

## Metadata

Every page exports `metadata` / `generateMetadata` built with `buildMetadata()` (`src/lib/seo/metadata.ts`) → title, description, canonical, Open Graph, Twitter.
